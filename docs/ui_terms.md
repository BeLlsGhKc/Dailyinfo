# UI 区块命名规范

本文档定义了 Dailyinfo 应用中各 UI 区块的统一命名，用于开发沟通和文档编写。

## 命名对照表

| 名称 | 含义 |
|------|------|
| 主窗口 | 整个 Dailyinfo 应用窗口 |
| 窗口控制栏 | 顶部显示 Dailyinfo、最小化、最大化、关闭的区域 |
| 任务标题栏 | 显示"每日任务"、日期、星期、历史按钮的区域 |
| 任务操作栏 | 输入框、搜索按钮、优先级按钮、添加按钮所在区域 |
| 任务区 | 中间的任务列表整体 |
| 任务行 | 任务区中的单条任务 |
| 完成勾选区 | 任务行左侧的完成按钮区域 |
| 优先级标识 | 任务行中的彩色圆点 |
| 时间信息 | 任务行右侧显示的截止日期、完成时间、过期提示 |
| 创建时间列 | 任务行最右侧显示 created_at 的列 |
| 任务统计栏 | 底部显示待办、今日完成、历史数量的区域 |
| 任务详情页 | 点击任务行后打开的详情弹窗 |
| 任务编辑区 | 任务详情页中的标题和内容编辑区域 |
| 详情操作区 | 任务详情页底部完成、保存、转换、删除按钮区域 |
| 主页面 | 默认待办任务页面 |
| 搜索页面 | 搜索结果页面 |
| 历史页面 | 已完成任务页面 |
| 日历面板 | 点击星期后打开的日历弹窗 |

## 代码对应关系

| 命名 | 代码位置 |
|------|----------|
| 窗口控制栏 | `TaskApp.setup_ui()` 中的 `win_row` |
| 任务标题栏 | `TaskApp.setup_ui()` 中的 `info_row` |
| 任务操作栏 | `TaskApp.setup_ui()` 中的 `toolbar` |
| 任务区 | `TaskApp.setup_ui()` 中的 `list_card` |
| 任务行 | `QTreeWidget` 中的 `QTreeWidgetItem` |
| 完成勾选区 | `check_btn` / `check_container` |
| 优先级标识 | `dot` (QLabel) |
| 时间信息 | `time_info` / `expire_label` / `deadline_label` |
| 创建时间列 | `time_label` (column 2) |
| 任务统计栏 | `footer` 中的 `stats_label` |
| 任务详情页 | `TaskDetailDialog` |
| 任务编辑区 | `title_edit` + `content_edit` |
| 详情操作区 | `btn_layout` |
| 主页面 | `refresh_task_list()` |
| 搜索页面 | `refresh_search_list()` |
| 历史页面 | `refresh_history_list()` |
| 日历面板 | `show_calendar()` |

## 使用建议

1. **代码注释**：使用上述命名描述 UI 区块
2. **Bug 报告**：使用上述命名描述问题所在区域
3. **需求文档**：使用上述命名描述 UI 变更
4. **沟通交流**：统一使用上述命名避免歧义
