# UI 区块命名规范

本文档定义 Dailyinfo 的 UI 区块命名，用于需求沟通、问题描述、代码注释和文档编写。

## 总体命名

| 名称 | 含义 |
|------|------|
| 主窗口 | Dailyinfo 的整个应用窗口 |
| 毛玻璃外壳 | 主窗口最外层圆角容器 |
| 页面主体 | 主窗口内部除系统边距外的主要内容区域 |
| 顶部栏 | 包含品牌、窗口控制栏、页面标题、日期和历史按钮的整体区域 |
| 窗口控制栏 | 右上角最小化、最大化、关闭按钮所在区域 |
| 窗口控制按钮 | 最小化、最大化、还原、关闭等自绘按钮 |
| 页面标题区 | 显示待办任务、已完成任务或搜索结果标题的区域 |
| 日期入口区 | 显示日期、星期按钮和历史按钮的区域 |
| 任务操作栏 | 输入框、搜索按钮、优先级按钮和添加按钮所在区域 |
| 设置入口 | 任务操作栏右侧打开设置弹窗的按钮 |
| 任务区 | 中间的任务列表整体 |
| 任务统计栏 | 底部显示待办、今日完成和历史数量的区域 |

## 任务列表命名

| 名称 | 含义 |
|------|------|
| 任务行 | 任务区中的单条任务 |
| 完成勾选区 | 任务行左侧的完成或取消完成按钮区域 |
| 完成按钮 | 待办任务左侧的空方框按钮 |
| 取消完成按钮 | 历史任务左侧的绿色对钩按钮 |
| 优先级标识 | 任务行中的彩色圆点 |
| 任务内容区 | 显示任务类型图标、标题和部分时间信息的区域 |
| 时间信息 | 任务内容区右侧的截止日期、完成时间或过期提示 |
| 创建时间列 | 最右侧显示创建时间的列 |
| 列表表头 | 任务区顶部的任务内容、完成时间、创建时间等标题 |
| 远期任务显隐按钮 | 任务表头中的小眼睛按钮，用于显示或隐藏远期计划任务 |
| 空状态提示 | 无任务时显示的提示文字 |

## 页面命名

| 名称 | 含义 |
|------|------|
| 主页面 | 默认待办任务页面 |
| 搜索页面 | 搜索结果页面 |
| 历史页面 | 已完成任务页面 |
| 日历面板 | 点击星期按钮后打开的日历弹窗 |
| 任务详情页 | 点击任务行后打开的详情弹窗 |
| 设置弹窗 | 点击设置入口后打开的存储配置弹窗 |
| 截止日期弹窗 | 创建计划任务时选择截止日期的弹窗 |
| 类型转换弹窗 | 任务详情页中转换任务类型时打开的弹窗 |

## 弹窗命名

| 名称 | 含义 |
|------|------|
| 弹窗外层 | 无标题栏弹窗的透明外层 |
| 弹窗容器 | 弹窗内部的白色圆角容器 |
| 弹窗标题行 | 弹窗顶部标题和关闭按钮所在行 |
| 弹窗关闭按钮 | 弹窗标题行右侧的自绘关闭按钮 |
| 详情编辑区 | 任务详情页中的标题输入框和内容编辑框 |
| 详情信息区 | 任务详情页中的创建时间和截止日期信息 |
| 详情操作区 | 任务详情页底部的完成、保存、转换和删除按钮区域 |
| 日历主体 | 日历面板中的 `HolidayCalendar` 控件 |
| 日历信息栏 | 日历面板底部显示农历、节气、节日和调休信息的文字 |
| 设置标题行 | 设置弹窗顶部标题和关闭按钮所在行 |
| 存储方式选择区 | 设置弹窗中选择本地文件或 MySQL 的区域 |
| MySQL 配置区 | 设置弹窗中填写主机、端口、用户名、密码和数据库名的区域 |
| 连接测试按钮 | MySQL 配置区中验证连接并创建目标数据库的按钮 |
| 设置提示文字 | 设置弹窗中显示依赖缺失、连接结果和重启提示的文字 |
| 设置操作区 | 设置弹窗底部取消和保存按钮所在区域 |

## 使用建议

- 描述问题时优先使用本文档中的 UI 名称。
- 修改界面时先确认目标区块名称，再定位对应代码。
- 涉及对齐问题时说明是标题区、任务区、表头还是任务行。
- 涉及弹窗问题时说明是任务详情页、日历面板、截止日期弹窗还是类型转换弹窗。
- 涉及时间显示问题时区分时间信息和创建时间列。
- 涉及存储配置问题时说明是设置弹窗、存储方式选择区、MySQL 配置区还是连接测试按钮。
- 涉及远期计划任务显示问题时说明远期任务显隐按钮当前是显示全部还是隐藏远期。
